# Dynamic trace-based sampling algorithm for memory usage tracking of enterprise applications

**2017 | IEEE High Performance Extreme Computing Conference (HPEC) | research paper**

**Authors:** Houssem Daoud, Naser Ezzati-Jivan, Michel R. Dagenais

**Core contribution:** This work studies dynamic trace-based sampling algorithm for memory usage tracking of enterprise applications in the context of software performance and systems analysis.

## Four-part research summary

### 1. Problem and motivation

Tracking memory behavior through detailed traces can be expensive for long-running enterprise applications.

### 2. Method and contribution

The paper studies dynamic trace-based sampling to track memory usage while controlling collection cost.
