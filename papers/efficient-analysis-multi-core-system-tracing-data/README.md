# An Efficient Analysis Approach for Multi-Core System Tracing Data

**2012 | 16th IASTED International Conference on Software Engineering and Applications (SEA 2012) | conference paper**

**Authors:** Naser Ezzati-Jivan, Michel R. Dagenais

**Core contribution:** The publisher abstract presents stateful trace analysis and abstraction for parallel-process traces, with shared computation and storage for recurring information.

### 1. Problem and motivation

The abstract frames stateless analysis of multi-core traces as costly when repeated information is recomputed or stored independently.
