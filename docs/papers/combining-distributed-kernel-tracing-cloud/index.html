Combining Distributed and Kernel Tracing for Performance Analysis of Cloud Applications

Loïc Gelle | Naser Ezzati-Jivan | Michel R. Dagenais

kernel-tracing system-tracing performance-analysis observability

distributed tracing kernel tracing cloud applications cross-layer performance analysis

Core contribution: This paper combines distributed tracing with kernel tracing to analyze cloud-application performance across software layers.

Problem and motivation

Distributed traces show request-level structure but may omit operating-system evidence needed to explain resource and scheduling effects.

Method and contribution

The approach correlates distributed-application trace information with kernel-level tracing for cross-layer performance analysis.

Findings and evidence

The paper contributes a combined tracing perspective for cloud applications; tracer configuration, correlation method, and measurements require full-text review.

Limitations and future directions

Limitations: The current catalog captures bibliographic evidence but not the full text; quantitative results, implementation details, and paper-specific validity threats require source review.

Future work: Evaluate correlation accuracy, overhead, cloud heterogeneity, and compatibility with modern OpenTelemetry pipelines.
