Core contribution: This work investigates Enhancing empirical software performance engineering research with kernel-level events: A comprehensive system tracing approach in the context of software performance and systems analysis.

Problem and motivation

Application-level measurements can miss operating-system events that explain performance variation.

Method and contribution

The work examines a comprehensive system-tracing approach that incorporates kernel-level events into empirical performance-engineering research.

Findings and evidence

It argues for richer performance evidence through kernel events; study-specific measurements require full-text review.

Limitations and future directions

Limitations: The current public record captures bibliographic metadata but not the paper's full text; quantitative claims and implementation details should be added after PDF or author-manuscript review.

Future work: Standardize event schemas, quantify instrumentation cost, and evaluate reproducibility across platforms.
