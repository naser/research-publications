Core contribution: The paper examines efficient cloud tracing across high-level application behavior and low-level system evidence.

Problem and motivation

Cloud performance diagnosis requires multiple levels of observation, but collecting all levels can impose substantial cost.

Method and contribution

The study organizes or combines tracing across high- and low-level cloud-system abstractions.

Findings and evidence

It contributes a multi-level cloud-tracing perspective; implementation and overhead results require full-text review.

Limitations and future directions

Limitations: The current catalog captures bibliographic evidence but not the full text; quantitative results, implementation details, and paper-specific validity threats require source review.

Future work: Compare adaptive collection policies, quantify cross-layer correlation cost, and test modern cloud platforms.
