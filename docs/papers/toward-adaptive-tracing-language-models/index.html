Core contribution: This work studies toward adaptive tracing: efficient system behavior analysis using language models in the context of software performance and systems analysis.

Problem and motivation

Tracing policies must balance diagnostic coverage against collection and analysis overhead.

Method and contribution

The paper explores language-model-supported analysis for making tracing more selective and behavior-aware.

Findings and evidence

It establishes an adaptive-tracing direction for efficient system observation; exact findings require full-text review.

Limitations and future directions

Limitations: The current public record captures bibliographic metadata but not the paper's full text; quantitative claims and implementation details should be added after PDF or author-manuscript review.

Future work: Compare adaptive policies against fixed tracing, verify safety, and test unseen workload behavior.
