# Integrated Modeling Tool for Indexing and Analyzing State Machine Trace

**2021 | 2021 IEEE International Symposium on Networks, Computers and Communications (ISNCC) | conference paper**

**Authors:** Simon Delisle, Naser Ezzati-Jivan, Michel R. Dagenais

**Core contribution:** The abstract presents an integrated tool for indexing, querying, and visualizing state-machine traces.

## Four-part research summary

### 1. Problem and motivation

Large state-machine traces need structured indexing and interactive views so analysts can filter and inspect state intervals efficiently.

### 2. Method and contribution

At abstract level, the tool models states, stores them in a special-purpose database, and provides filtering/highlighting with Gantt and XY visualizations for Linux and Windows examples.

### 3. Findings and evidence

The abstract indicates that the tool supports the described trace views; no scale, latency, or comparative metric is verified.

### 4. Limitations and future directions
