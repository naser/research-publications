Container Workload Characterization Through Host System Tracing

Madeline Janecek | Naser Ezzati-Jivan | Seyed Vahid Azhari

kernel-tracing system-tracing performance-analysis resource-analysis

Core contribution: This work investigates Container Workload Characterization Through Host System Tracing in the context of software performance and systems analysis.

Problem and motivation

Container behavior must be characterized without relying exclusively on instrumentation inside each workload.

Method and contribution

The work studies host-system tracing as a source of evidence for characterizing container workloads.

Findings and evidence

It contributes a host-observation perspective for container characterization; workload and metric details require full-text review.

Limitations and future directions

Limitations: The current public record captures bibliographic metadata but not the paper's full text; quantitative claims and implementation details should be added after PDF or author-manuscript review.

Future work: Assess isolation, multi-tenant interference, portability, and low-overhead continuous characterization.
