# Naser Ezzati-Jivan Publications

This repository is an agent-friendly, human-readable catalog of selected research papers by Naser Ezzati-Jivan. It provides stable bibliographic metadata, four-part research summaries, controlled topic links, citation formats, and authoritative source links.

## Scope of this release

Phase 1 contains **10 papers**: eight with verified public arXiv PDFs, one with a verified public CC-BY article page, and one with a verified public direct PDF. The repository does not redistribute publisher PDFs; each page links to the DOI, arXiv, or the authoritative open source.

See [the rollout outline](./outline.md) for what is included now and what remains for later phases.

## Record format

Each paper has a Markdown record for readers, a JSON record for agents and scripts, and a BibTeX file. The four-part summary separates problem, method, findings, and limitations/future directions. Version relationships are explicit when a published paper and public preprint coexist.

## Access and rights

A source link is not automatically a redistribution license. The catalog links readers to the publisher, DOI, arXiv, ACL Anthology, or an openly licensed proceedings page. No publisher PDF is copied into this repository.
